# 🏥 MedProfit Analytics — 병원 수익성 분석 플랫폼

병원 경영 컨설턴트를 위한 전문 수익성 분석 Streamlit 애플리케이션입니다.

---

## 🚀 실행 방법

### 1. 의존성 설치
```bash
pip install -r requirements.txt
```

### 2. 앱 실행
```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 접속

---

## 📦 기능 구성

### 🆓 무료 기능
| 탭 | 기능 |
|---|---|
| 핵심 요약 | 전체 KPI 대시보드, 진료과별 매출/이익 차트, 빠른 경영 진단 |
| 진료과별 분석 | 기본 손익 현황표, 비용 구조 분석 |
| 트렌드 분석 | 월별 매출/이익 트렌드, 히트맵 |
| 데이터 입력 가이드 | 엑셀 형식 안내, 샘플 템플릿 다운로드 |

### 💎 프리미엄 기능 (라이선스 키 필요)
| 탭 | 기능 |
|---|---|
| 진료과별 분석 | 수익성 포트폴리오 매트릭스, BEP 분석, 의사 생산성 분석 |
| 행위별 손익 | 행위별 마진율 분석, 트리맵, 저마진 행위 경고 |
| 트렌드 분석 | 차년도 매출 예측, 성장 시나리오 |
| 시뮬레이션 | 수가·환자수 시뮬레이션, 비용 최적화, 신규 진료과 ROI |
| 전략 보고서 | SWOT 분석, 3개년 로드맵, KPI 목표 |
| 리스크 진단 | 리스크 레이더, 스트레스 테스트, 취약점 진단 |

## 📋 데이터 형식

### Sheet 1: 월별_진료과_데이터 (필수)
| 컬럼명 | 설명 | 단위 |
|---|---|---|
| 월 | 1월~12월 | - |
| 진료과 | 내과, 외과 등 | - |
| 매출(만원) | 해당 월 매출 | 만원 |
| 인건비(만원) | 인건비 합계 | 만원 |
| 재료비(만원) | 재료비·약품비 | 만원 |
| 운영비(만원) | 기타 운영비 | 만원 |
| 환자수 | 연인원 | 명 |
| 의사수 | 해당 진료과 | 명 |

### Sheet 2: 행위별_데이터 (선택)
| 컬럼명 | 설명 |
|---|---|
| 진료과 | 진료과명 |
| 행위명 | 진찰료, 처치비 등 |
| 건수 | 연간 시행 건수 |
| 매출(만원) | 연간 행위 매출 |
| 직접비용(만원) | 직접 소요 비용 |
| 마진율(%) | (매출-비용)/매출 |

## 🔑 라이선스 키 관리

현재 데모 키: `MEDPROFIT2024`

실제 배포 시 `app.py`에서 다음 줄을 수정하세요:
```python
PREMIUM_KEY = "MEDPROFIT2024"  # 실제 키로 변경
```

또는 Streamlit Secrets를 활용한 키 관리 권장:
```toml
# .streamlit/secrets.toml
PREMIUM_KEY = "your-secure-key"
```

```python
# app.py
PREMIUM_KEY = st.secrets["PREMIUM_KEY"]
```
